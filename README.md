# LinuxSecurityCheck - Linux系统安全管理TUI程序

**ALSCC (Advanced Linux Security Compliance Checker)** - 一个基于Go语言开发的终端用户界面(TUI)程序，专注于Linux系统的全面安全管理和合规检查。

## 项目状态

**当前版本**: Phase 1 Complete  
**开发状态**: 一阶段完成，准备二阶段开发  
**核心功能**: 全部实现并优化完成  

## 核心功能特性

### 🔐 用户密码批量管理
- **智能用户筛选**: 自动识别系统用户（UID≥1000，排除服务账户）
- **多选批量操作**: 支持单选、全选、条件选择用户
- **三种密码策略**:
  - **统一密码**: 所有用户使用相同的安全密码
  - **规则密码**: 前缀+递增数字+特殊字符（如：MyPass001!）
  - **随机密码**: 每用户独立的8位强随机密码
- **安全保护**: 禁止修改root用户密码，防止系统锁定

### ⏰ 密码过期智能检查
- **自动分类显示**:
  - 已过期用户（≥90天）- 红色警告
  - 临近过期用户（75-89天）- 黄色提醒  
  - 正常用户（<75天）- 绿色正常
- **批量处理**: 支持选择过期/临近过期用户批量修改密码
- **实时状态**: 动态更新用户密码状态信息

### 🔒 登录安全策略管理
- **多系统支持**: CentOS、Ubuntu、Debian、Kylin、openEuler、RHEL、Fedora、SUSE、Arch、Alpine
- **智能检测**: 自动识别Linux发行版和PAM配置
- **双重保护**: 
  - 标准配置：全用户锁定策略
  - 安全配置：root用户白名单保护
- **紧急恢复**: 一键解锁所有被锁定账户
- **配置备份**: 自动备份原PAM配置文件
- **多模块支持**: pam_faillock、pam_tally2等

### 🛡️ 系统安全合规检查（72项）
- **全面检查覆盖**:
  - 开发工具和编译器安全
  - 用户权限和账号管理
  - 口令策略和认证安全
  - 网络服务和端口安全
  - 日志审计和监控配置
  - SSH和远程访问控制
  - 系统服务和进程安全
  - 文件权限和资源控制
- **风险等级分类**: 极高、高、中、低风险智能分级
- **双模式运行**:
  - **严格模式**: 只检查不修改，适合生产环境审计
  - **标准模式**: 检查并提供详细修复建议
- **实时进度**: 真实的步骤式进度条显示
- **智能优化**: 资源密集型检查可选跳过

### 🔍 弱口令检测系统
- **多Hash算法支持**: MD5-crypt、SHA256-crypt、SHA512-crypt、DES-crypt
- **纯Go实现**: 集成SHA256-crypt算法，无外部依赖
- **Top1000字典**: 内置常用弱口令字典攻击
- **包含root检测**: 重点检查root用户弱口令风险
- **性能可调**: 支持并发数和超时时间配置
- **实时进度**: 逐用户检测进度显示
- **详细报告**: 显示Hash类型、检测耗时、风险等级

### 🎨 专业TUI界面
- **ALSCC品牌标识**: 专业ASCII艺术字标题
- **多彩界面设计**: 丰富的颜色和样式区分
- **响应式布局**: 适配不同终端尺寸
- **直观操作**: 完整的键盘导航和快捷键
- **实时反馈**: 所有操作都有进度和状态显示
- **错误处理**: 友好的错误消息和恢复机制

## 安全规则

- **禁止修改root用户密码**
- **只处理系统用户**（UID≥1000）
- **自动过滤服务用户**（shell包含nologin或false）
- **强密码规则**：8位密码，包含大小写字母、数字和特殊字符

### 在Windows下交叉编译

#### 方法一：使用构建脚本（推荐）

**PowerShell脚本：**
```powershell
.\build.ps1
```

**批处理脚本：**
```cmd
build.bat
```

#### 方法二：手动编译

**安装依赖：**
```powershell
$env:GOPROXY="https://goproxy.cn,direct"
$env:GOSUMDB="sum.golang.google.cn"
go mod tidy
```

**交叉编译为Linux可执行文件：**
```powershell
$env:GOOS="linux"
$env:GOARCH="amd64"
go build -o LinuxSecurityCheck-linux .
```

#### 方法三：使用Makefile
```cmd
make build
```

### 在Linux系统上运行

将编译好的 `LinuxSecurityCheck-linux` 文件传输到Linux系统，然后：

```bash
# 添加执行权限
chmod +x LinuxSecurityCheck-linux

# 运行程序（需要root权限）
sudo ./LinuxSecurityCheck-linux
```

## 密码生成规则

### 统一密码
用户输入一个符合安全规则的密码，所有选中用户使用相同密码。

### 规则密码
用户输入前缀，系统自动添加递增数字和特殊字符后缀。
格式：`用户前缀 + 递增数字 + !`
例如：输入前缀"MyPass"，生成MyPass001!, MyPass002!, MyPass003!

### 随机密码
- 8位长度
- 包含大写字母、小写字母、数字、特殊字符
- 每个用户生成唯一的强随机密码

## ⚠️ 重要安全警告

### 锁定策略配置风险
1. **root用户锁定风险**: 如果选择"标准配置"，root用户可能被锁定，导致系统无法管理
2. **推荐配置**: 生产环境请选择"安全配置 - root用户白名单"
3. **紧急恢复**: 如果root被锁定，请使用提供的 `emergency_unlock.sh` 脚本
4. **备份重要性**: 程序会自动备份PAM配置，但建议手动额外备份

### 使用建议
- 在生产环境使用前，请先在测试环境验证
- 配置锁定策略时保持至少一个SSH连接不断开
- 确保有物理控制台访问权限
- 详细恢复指南请查看 [EMERGENCY_RECOVERY.md](EMERGENCY_RECOVERY.md)

## 注意事项

1. **权限要求**: 程序必须以root权限运行
2. **密码安全**: 修改完成后会显示新密码，请妥善保存
3. **系统兼容**: 支持主流Linux发行版，详见SYSTEM_SUPPORT.md
4. **备份建议**: 修改密码前建议备份重要数据
5. **锁定策略**: 配置锁定策略前会自动备份原PAM配置文件
6. **按键说明**: q键退出程序，Esc键返回上一级界面
7. **系统检测**: 程序会自动检测系统类型并适配相应的PAM配置

## 技术架构

### 核心文件结构
```
LinuxSecurityCheck/
├── main.go              # 程序入口和权限检查
├── model.go             # 数据模型和状态管理
├── views.go             # TUI界面渲染和ALSCC标识
├── updates.go           # 事件处理和状态更新
├── users.go             # 用户管理和密码操作
├── password.go          # 密码生成和验证逻辑
├── lockpolicy.go        # 登录锁定策略管理
├── security.go          # 安全检查核心逻辑
├── security_linux.go    # Linux平台安全检查实现
├── weakpass.go          # 弱口令检测（含SHA256-crypt算法）
├── Top1000pass.txt      # 弱口令字典文件
├── emergency_unlock.sh  # 紧急解锁脚本

```

### 技术特点

- **步骤式执行**: 真实进度更新，优秀用户体验
- **模块化设计**: 功能分离，易于维护和扩展
- **内存优化**: 智能输出截断，避免界面卡顿
- **并发控制**: 可配置的性能参数和资源管理

### 依赖库
- **Bubble Tea**: TUI框架和事件处理
- **Lip Gloss**: 样式和颜色管理
- **Go标准库**: 系统调用和加密算法
